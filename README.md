# My Portfolio Website

A personal portfolio website developed using WordPress to showcase my profile, technical skills, projects, hobbies, blog posts, and development journey.

## 📌 About the Project

This is my personal portfolio website created using WordPress and developed locally using XAMPP.

The website provides visitors with an organized overview of my background, skills, projects, interests, blog posts, and contact information. The content, layout, and visual styling were customized using WordPress's built-in features.

A contact form plugin was also integrated to provide a working contact form for visitors.
